# デザインの考え方

文章も画面も、「シンプルで読みやすく、やさしい」ことを基本にしています。
ここでは、その考え方だけをまとめます。決まった値は `reading/reading.css` を見てください。

## 1. やさしい日本語

- 結論を先に書きます。補足は、読む人の次の判断や行動に関わることだけにします。
- 1文に1つのこと。短い文で区切ります。
- むずかしい言葉は、身近な言い方にします。専門用語は、具体例から入ってつなげます。
- 直訳調や硬い言い回し、相手を責めるように響く言い方を避けます。
- 名詞が続いて造語のように見えるときは、助詞を足して自然な文にします。
- 一般的なカタカナ語で通じるものは、英単語をそのまま使わずカタカナにします。
- 日本語と英数字が混ざるとき、英数字の前後にスペースを入れません。
- 箇条書きは、内容のまとまりごとに短く。一続きで読むほうが自然な文は、無理に箇条書きにしません。
- 大事な制約・分からないこと・残っていることは、短くするために省きません。

## 2. 文字と余白が主役

- 画面の主役は文章です。見出し・段落・短い箇条書きを中心にします。
- 表や図は、関係を示すのに必要なときだけ使います。
- 読みやすい文字の大きさ（本文 17〜18px）と、ゆったりした行の高さ（1.7〜1.8）にします。
- 1行の長さは長くしすぎません（本文の幅は 640px まで）。
- 読み物は、広い枠（960px）を画面の中央に置き、文章はその左に寄せます。図や表は枠いっぱいまで広げてかまいません。
- 要るものだけに絞ります。箱を増やさず、余白と大きさで分けます。

## 3. 線を引かない、影は浮くものだけ

- ボーダー（線・枠）は使いません。カード・行・チップは、面の明るさの差だけで分けます。
- 影は、メニュー・シート・知らせ・＋ボタンなど、浮いている要素だけに付けます。
- 影を付けるものには、輪郭が分かる程度の細い縁を添えてもかまいません。

## 4. 控えめな色

色は用途で決めます。意味のないところに色を使いません。

- 青：要点・お知らせ・リンク
- 緑：完了
- 赤：エラー・取り消せない操作
- オレンジ：返事待ち・期限が近い
- ほかは黒とグレー

## 5. 文字の太さ

- medium（500）を強調の基本にします。
- bold（600〜700）は、ページや区切りの見出しだけ。
- 一覧の行やカードの中は、medium と regular（400）の2段で組みます。区別は大きさ・色・位置でつけます。

## 6. 動きは短く、意味のあるものだけ

- 動きは、何が起きたかを伝えるときだけ使います（開く・閉じる・状態が変わる・追加と削除）。飾りの動きは足しません。
- 短く（多くは 0.15〜0.3 秒）、途中で止めても自然につながるようにします。ばねの動きが合う場面では、ばねを使います。
- キー操作のように何度も繰り返す操作には、動きを付けません。
- 中途半端な重なりや、途中の色を見せないようにします。
- 「視差効果を減らす」（reduced-motion）の設定では、形を動かさず、薄くして入れ替えるだけにします。

## 7. 静かな画面

- 次に進む直前に要る説明や確認は、元の画面に足さず、必要なときだけ下から出すなどで見せます。
- 説明には、使う人がいま見ているもの（押したボタンの文言など）をそのまま使います。
- 消す・取り返しのつかない操作は、色（赤）で重さを伝え、1回のタップで終わらせません。ふだんの操作には手間を足しません。

## 8. 仕上げで確かめること

- ぼやけた画像、コマ落ちする動き、ぱっと切り替わるだけの画面遷移を残しません。
- 長い名前、長い一覧、空の状態など、いちばん悪いデータを入れて崩れないか試します。
- 文字は枠から 12px 以上離し、端どうしを 1〜3px だけずらすような半端なずれを作りません。
- アイコンは1つのセット・1つの太さ・1つの大きさにそろえます。
- 値（色・余白・大きさ）は1か所にまとめ、場所ごとに別の数字を作りません。
